# YouTube Music Downloader v2.1.2 — Cleaner playlist header

- Removed the floating "Hide setup · expand list" button.
- Removed the "Display sorting only" badge.
- Setup remains accessible through the collapsible "Playlist setup" section, which closes after a successful scan.
- Sorting, song selection, downloading, and M3U8 order keep their existing behavior.

Download **YouTubeMusicDownloader-Desktop-v2.1.2-win-x64.zip**, choose **Extract All**, and run **YouTubeMusicDownloader.Desktop.exe**. Keep the entire folder together. Python, .NET, FFmpeg, and FFprobe are included.

Reuse your private YouTube `cookies.txt` and existing music folders. Private cookies and downloaded music are not included. Some downloads require the optional Docker PO-token provider described in the README.

Windows x64; unsigned build. A SHA-256 checksum is provided as a separate asset.

Validation: 44 Python tests, 57 desktop checks, and a screenshot review of the compact 925-song playlist layout. No live YouTube download was performed.
