# App icon

- `app-icon.png` is the original generated image with a transparent exterior.
- `app-icon.ico` packages the same image at 16, 24, 32, 48, 64, 128, and 256 pixels for the Windows EXE.
- The project embeds the ICO in the executable and uses the PNG for its window, title bar, and sidebar.
- Created with the built-in image-generation tool. Pillow was used only to package the image in Windows ICO format.

## Generation prompt

Use case: logo-brand. Asset type: finished Windows executable app icon for a YouTube Music playlist downloader called Music Sync. Create one premium, polished icon: a centered rounded-square deep forest green tile with a bold luminous mint music note cleverly integrated with a downward download arrow and shallow tray. Simple coherent readable silhouette with thick strokes, elegant restrained beveled depth, subtle teal edge highlight; matches a dark forest green desktop application with mint accents. Face-on orthographic square composition, tile fills 90 percent of canvas, no perspective. Exterior outside the rounded tile is genuinely transparent. No words, no letters, no YouTube trademark, no tiny details, no mockup, no watermark. Should be recognizable when reduced to 16, 32, 48 pixels as a taskbar icon. Single standalone square icon.
